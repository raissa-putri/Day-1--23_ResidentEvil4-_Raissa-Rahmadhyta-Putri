Tujuan & Kegunaan Repository :
Repository bertujuan untuk menyimpan, mengelola, dan mendokumentasikan file atau proyek secara online agar lebih teratur. Repository juga berguna untuk memudahkan pengguna dalam memperbarui file, melihat riwayat perubahan, bekerja sama dengan orang lain, serta membagikan hasil pekerjaan dengan lebih mudah.

Rangkuman Materi :
1. Prompt Engineering
   Prompt Engineering adalah cara merancang intruksi agar AI memberikan jawaban yang tepat, relevan,dan sesuai kebutuhan.
   Prompt adalah instruksi atau masukan yang diberikan kepada AI untuk mendapatkan hasil tertentu.
   Prompt bisa berupa pertanyaan sederhana, kata kunci, instruksi panjang, maupun potongan kode.
   Good Prompt Structure:
   1. Role: Peran yang diberikan kepada AI.
   2. Task: Tugas yang harus dikerjakan AI.
   3. Context: Konteks atau informasi pendukung.
   4. Format: Bentuk hasil yang diinginkan.
   Keuntungan Prompt Engineering:
   - Meningkatkan performa AI model.
   - Mengurangi bias dan respons yang offensive.
   - Meningkatkan kontrol dan predictability.
   - Memberikan pengalaman yang lebih baik.
2. Git dan Github
   Git adalah Version Control System yang melacak siapa, kapan, dan apa saja yang sudah diubah dalam suatu file. Git diciptakan oleh Linus Torvalds pada tahun 2005.
   GitHub adalah platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi.
   Perbedaan Git dan GitHub:
   - Git: Sistem version control terdistribusi (DVCS) untuk melacak dan mengelola perubahan kode secara lokal.
   - GitHub: Platform berbasis web untuk menyimpan repository Git secara online dan mendukung kolaborasi.
3. Git Workflow :
   Git Workflow memiliki tiga bagian:
   1. Working Directory/Tree: Salinan proyek yang sedang dikerjakan. File di dalamnya dapat digunakan atau dimodifikasi.
   2. Staging Area: Tempat menyimpan informasi perubahan file yang akan dimasukkan ke commit berikutnya.
   3. Git Directory: Tempat Git menyimpan metadata dan object database proyek. Bagian ini berisi informasi yang dibutuhkan Git untuk mengelola proyek.

  Poin - Poin Penting atau Pengetahuan Baru :
  1. GitHub merupakan platform untuk menyimpan dan mengelola proyek secara online.
  2. Repository digunakan sebagai tempat penyimpanan file dan kode program.
  3. Git digunakan untuk mencatat dan mengelola perubahan pada file atau proyek.
  4. README berfungsi untuk memberikan informasi dan penjelasan mengenai isi repository.
  5. Fitur GitHub memudahkan pengguna untuk bekerja sama dan berbagi proyek dengan orang lain.
